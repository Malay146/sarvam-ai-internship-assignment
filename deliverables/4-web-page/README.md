# Responsive web page: Indus Cowork

**Live:** https://sarvam-ai-internship-assignment-4of.vercel.app/

Full-page exports, with every section in its finished state:
- [Phone, 375](indus-cowork-375.png)
- [Tablet, 768](indus-cowork-768.png)
- [Desktop, 1440](indus-cowork-1440.png)

The page rearranges between those sizes rather than shrinking. The rules are in [`../1-design-system/layout.md`](../1-design-system/layout.md) and the page recipe in [`../1-design-system/recipes/landing-page.md`](../1-design-system/recipes/landing-page.md). It is checked at 10 widths (320–1920) in Chromium and WebKit.

Regenerate the exports with `node scripts/export-page.mjs` (from the repo root).
